# POSTTEST ALPROG KELOMPOK 2

## Deskripsi Proyek

Repository ini merupakan dokumentasi dan implementasi tugas Posttest Algoritma dan Pemrograman yang dikerjakan oleh Kelompok 2 menggunakan bahasa pemrograman C++. Proyek ini dibuat sebagai bagian dari proses pembelajaran untuk menerapkan konsep-konsep dasar pemrograman, mulai dari penggunaan variabel, percabangan, perulangan, fungsi, hingga pengolahan data dalam sebuah program yang terstruktur.

Melalui pengembangan proyek ini, setiap anggota kelompok berkontribusi dalam proses analisis permasalahan, perancangan algoritma, implementasi program, serta pengujian hasil agar program dapat berjalan sesuai dengan kebutuhan yang telah ditentukan. Selain bertujuan untuk memenuhi tugas akademik, proyek ini juga menjadi sarana untuk meningkatkan kemampuan berpikir logis, pemecahan masalah, dan kerja sama tim dalam pengembangan perangkat lunak sederhana.

## Implementasi

Program dikembangkan menggunakan bahasa pemrograman C++ dengan memanfaatkan berbagai konsep dasar yang telah dipelajari selama perkuliahan Algoritma dan Pemrograman. Struktur program dirancang agar mudah dipahami dan dikembangkan lebih lanjut, sehingga setiap fitur yang tersedia dapat dijalankan secara efektif melalui antarmuka berbasis terminal (console).

Seluruh proses pengembangan dilakukan dengan memperhatikan prinsip penulisan kode yang rapi dan terorganisir, sehingga program tidak hanya berfungsi dengan baik tetapi juga mudah untuk dibaca, dipelajari, dan dipelihara di kemudian hari.
